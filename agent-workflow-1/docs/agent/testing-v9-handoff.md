# V9 测试设计与执行交接

2026-11-04。本轮**仅生产代码和测试设计**；未编写测试代码、未编译、未执行任何测试或真实模型调用。后续模型按本设计实施，不把本文列出的结果当作已经通过。

## 测试架构与成本约束

- 默认真实模型调用 **0**，不启动 embedding、reranker 或真实 IdP。使用本地兼容工具调用响应的 HTTP/TLS 替身和固定 usage，保留实际 Spring AI 适配器与 V9 HttpRequestFactory，以覆盖 SDK 包装后的错误传播。
- 复用一个 MySQL 8 临时库，完成 V10→V11 迁移；预算并发、行锁、提交/取消和崩溃结算必须使用实际 MySQL，不能用 H2/mock 证明。
- 数据仅两名用户、两个租户、一个会话、少量合成工具结果。主/备两个 HTTP endpoint 可由一个替身进程提供，用 request latch 控制完成时序。
- 不做大规模压测，不为每个故障重启全套服务，不调用真实模型验证 SSE。浏览器只检查一次进度/取消和一次身份切换，安全断言主要放在服务/API。
- 先 Java 编译/装配及迁移，再执行下方 8 组代表场景。失败只修复、重跑相关组，不自动扩大 V1–V8 全量回归。

## 关键断言和故障注入

1. **预算守恒**：对每个 wallet 验证预留等于其 STARTED attempts 的预留和；accounted 等于已结算 attempts 的记账估算和。正常、异常、取消、收尾各检查一次，不只检查“余额减少了”。存储价格快照与使用的路由一致。
2. **实际/未知分离**：usage 缺失时 input_tokens/output_tokens 必须 null；有 usage 但回答格式错误时允许保守 unknown，不能因此声明零成本。价格估算不能断言等于供应商账单。
3. **提交原子性**：分别在 task 审计保存、conversation CAS、terminal event 写入时注入 DB 失败，断言事务回滚，run 不成功、答案不通过结果接口暴露。取消与 publish 使用真实不同连接控制锁顺序。
4. **授权续检**：最终答案 ready 后撤销来源，再读 result/原 task/会话；重连 SSE 仍只得到元数据，不得借事件重放获取过期正文。已有 V8 来源图夹具可以复用。
5. **身份传递**：异步先执行 alice 再 bob，检查模型/工具上下文的 subject/tenant；线程复用后无残留。停止后启动新的无身份任务不能借旧 SecurityContext 调用 MCP。测试用 JWT 可本地签名，不访问企业 issuer。
6. **取消不是退款**：服务替身在客户端取消后继续处理，断言本地 run 终止但账本保守记 unknown。不要让“socket 已关闭”成为“供应商无计费”的断言。
7. **费用/期限基准**：测试价格使用明确的合成数值，不从网络查实时价格。短 deadline 可用合法测试配置（最低 5 秒）与 latch；不要为每个断言 sleep 60 秒。无法缩短的故障最多测一个代表样例。
8. **跨版本**：V9 的费用账本仅覆盖 Java 只读问答，旧写工作流和独立 RAG 生成不在范围；不要写成“所有模型调用都已纳入”。V6/V7/V8 未执行的验证仍列待办，不用本轮通过的场景替代。
