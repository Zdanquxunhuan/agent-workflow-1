## 本版实现

- Java 管理会话权威状态：tenant、owner、只读 participants、revision、有效期、完整问答轮次和摘要；memory/JDBC 两种存储。会话最多 100 轮，列表最多 50 条。
- owner 独占写入与管理；参与者只读，租户相同且显式授权才能读取，ADMIN 不自动绕过 owner。分享业务问答表示 owner 授权参与者查看该会话，知识来源仍由 RAG 按当前读者重新检查。
- 每次写入使用 revision CAS；先占用运行轮次，再请求模型，不在模型请求期间持有数据库事务。相同幂等 key/问题的成功请求重放；变更问题、运行中或失败 key 冲突。网络失败后可用原 key 重放确认，不能自动重复模型调用。
- 上下文最多保留最近 4 个原始轮次中的成功问答对，超预算从最旧整对裁剪。工具请求/结果留在本轮循环，不跨轮保存进 prompt，避免孤立 tool_call。完整可见问答保留在会话记录，与送模上下文分离。
- 较早内容采用确定性订单话题摘要：只保留最近显式 ORD-* 指代，带来源 task、摘要版本和覆盖水位，不调用模型摘要、不缓存订单状态或政策结论。不是通用语义摘要；未显式出现订单编号的复杂跨轮指代仍依赖窗口内原文。
- 历史展示、送模、返回与幂等回放检查来源权限；来源依赖写入独立任务依赖表，直接读取派生任务也递归复核原任务证据/委托。知识版本变化、删除、ACL/委托撤销或过期时拒绝返回受影响正文。依赖遍历去重、最多 100 个任务，共用一次 RAG 复核 deadline。
- 原单轮 `/api/v1/agent/chat` 保持接口；新增 `/conversation.html` 简洁页面，令牌只驻留页面内存，文本使用 textContent 展示。

## API

所有 API 都要求已有 JWT 身份，tenant 不从请求体接收。路径前缀 `/api/v1/conversations`：

| 方法与路径 | 请求/行为 |
| --- | --- |
| POST / | 创建当前用户会话，返回 revision=0 |
| GET / | 返回授权会话 id/owner/revision/expiresAt；不返回正文 |
| GET /{id} | 重授权后返回完整会话 |
| POST /{id}/messages | `Idempotency-Key`（1–80 位字母数字、下划线或连字符），body：`{"revision":0,"message":"查询 ORD-1001"}` |
| PUT /{id}/participants | owner 设置只读主体集合：`{"revision":3,"subjects":["alice"]}`，最多 10 个；运行中不可更改 |
| POST /{id}/cancel | owner 提交当前 revision，标记运行轮次失败并隔离迟到结果 |
| DELETE /{id}?revision=N | owner 清除会话内容并留删除标记；迟到模型结果不能恢复会话 |

成功发送返回 conversationId、最新 revision、turn、estimatedTokens、omittedTurns。重放返回估算/裁剪值 0（本次未组装 prompt）。版本可能在运行中增加，不应自行假设每轮只增加一次；刷新 GET 或列表获取当前 revision。若进程中断留下 RUNNING，owner 用列表取得 revision 后 cancel，再使用新 key 发起下一轮，不自动接管执行。

## 配置与迁移

`CONVERSATION_CONTEXT_BUDGET=6000`：仅历史和当前问题的保守 UTF-8 字节估算（加消息开销），不是实际 token 或账单用量。合法区间收敛为 512–12000。原 V5 64000 字节消息上限、工具/模型轮次与输出限制继续生效。当前问题与摘要都放不下时返回 MODEL_CONTEXT_BUDGET，不截断用户问题。

`CONVERSATION_RETENTION_DAYS=7`：创建时固定有效期，限制为 1–30 天，不随追问续期；过期立即不可读。定时清理每分钟处理至多 100 条过期 JDBC 会话，memory 清理本进程过期项。删除会话不删除独立任务审计、业务数据或知识授权记录；这些沿用原保留规则。

Flyway V8 新增 conversations 与 task_knowledge_dependencies。会话快照采用有界 JSON，revision 条件更新；小规模会话避免引入多表消息事务，后续规模增长可拆分消息表。**迁移没有实际运行**，后续由测试负责人在专用 MySQL 验证后安排工作库升级，不能直接将本次代码当已验证可部署版本。

## 边界

模型调用、任务审计与会话提交不是跨系统原子事务。若审计已完成但会话 CAS 失败，不返回成功会话响应，独立审计可能保留终态；不能回滚外部模型用量。取消/删除阻止后续提交，不保证中断已发出的 HTTP 请求或停止计费。撤权检查与响应之间仍有分布式时序窗口，不声称线性一致授权。

会话页面只提供基本操作，参与者管理通过 API；没有 SSE、长期记忆、通用 LLM 摘要或企业 token exchange。新鲜工具查询与引用结构校验不证明语义正确。“那运费呢”必须结合当前政策检索，系统不会创造订单中不存在的运费字段。
