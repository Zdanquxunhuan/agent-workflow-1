## 修复的问题

触发：JDBC + 长期记忆启用时，`POST /api/v1/memories` 创建偏好返回 500。

原因：`MemoryStore` 标注为 Spring Repository，异常转换创建 CGLIB 代理。`MemoryService` 直接读取 `store.jdbc` 字段，读到的是代理壳对象的未初始化字段，而不是实际目标对象的 JdbcTemplate。手动 new 对象的测试很难暴露这个问题。

修复：JdbcTemplate 改为 private；配额查询、自动提取设置、提取任务检查/计数、源任务锁和重新授权事件通过仓储方法访问。原事务仍使用同一个 DataSource，未移除代理或关闭异常转换。

验证：真实 Spring 容器中创建候选偏好 → 确认 → V6 会话消费该偏好并记录来源 → 删除偏好 → 读取旧会话被 MEMORY_CHANGED 拒绝。所有受影响生产代码重新编译。其他仓储入口采用同一修复方式，但没有宣称逐一执行过全部提取/索引场景。
