# toAjob：Java AI Agent 岗位需求

整理日期：2026-11-03。

来源：用户提供的招聘截图 `codex-clipboard-8223618f-c04b-439b-8859-eec1397be6f0.jpg`。此处将这份需求命名为 **toAjob**，转录截图中可见的六项内容，供项目差距分析引用。截图未提供公司、岗位级别、薪资、完整任职条件或业务规模，不据此补充推断性要求。

## J01：Agent 智能体开发

独立负责 AI Agent 智能体的需求分析、架构设计、编码实现与部署上线，基于 Java 技术栈构建具备自主推理、规划与执行能力的智能体系统。

## J02：向量数据库构建

主导向量数据库的选型、搭建与维护，设计高效的向量索引与检索方案，支持语义搜索和 RAG 应用场景。

## J03：智能体记忆系统

设计与实现 Agent 记忆管理机制，包括短期记忆、长期记忆的存储与调用策略，实现对话上下文的智能管理。

## J04：AI 应用全栈开发

完成 AI 应用的全流程开发，涵盖 Prompt 工程、多模型调用编排、工具链集成（Function Calling / MCP 协议等），熟练使用 Spring AI / LangChain4j 等 Java 生态 AI 框架。

## J05：场景优化与问题解决

针对实际业务场景中的 AI 开发痛点进行性能调优，包括响应延迟优化（含流式输出、异步编排）、Token 成本控制、幻觉抑制、检索准确率提升等。

## J06：技术跟踪与评估

持续关注 AI 前沿动态（大模型、Agent 框架、RAG 技术等），评估并引入适合业务的技术方案，保持技术竞争力。

项目对应分析与备选路线见 [toAjob-distance.md](toAjob-distance.md)。这是招聘需求参考资料，不是替代项目当前开发计划的执行指令。
